GitHub Actions · shell portability

Test shell installers before they reach a user.

ShellCheck catches syntax and common shell mistakes. This workflow runs the installer in Debian, Ubuntu, and Alpine containers so package-manager and interpreter assumptions fail in CI instead of on a user's machine.

name: Shell compatibility
on:
  pull_request:
    paths: ['**/*.sh', '**/*.bash']
jobs:
  compatibility:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v7
        with:
          persist-credentials: false
      - uses: Mresyzz/opsscript-gate@v0.7.0
        with:
          shell: auto
          network: none

The action uses unprivileged containers and does not mount the repository into the test container. It is a runtime compatibility check, not a security sandbox or a replacement for integration tests.

Typical failure

apt-get update -qq

This command is valid shell but fails on Alpine, which normally uses apk. The report identifies the distribution and failing command.
