InstallReady

Shell portability in CI

ShellCheck finds syntax issues. Runtime checks find distro issues.

ShellCheck is excellent for static shell analysis. It does not tell you whether an installer can run when Ubuntu has apt-get and Alpine has apk, or when a script quietly depends on Bash.

What the runtime check covers

  • Debian, Ubuntu, and Alpine container environments.
  • Missing commands, package-manager assumptions, interpreter mismatches, and interactive hangs.
  • Commit-pinned reports that can run in your repository's own GitHub Actions workflow.

  with:

OpsScript Gate complements ShellCheck; it does not replace syntax analysis or your project's integration tests.
