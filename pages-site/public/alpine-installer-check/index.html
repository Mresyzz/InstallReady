Debian · Ubuntu · Alpine

Does your Linux installer work outside Ubuntu?

A script can pass a shell syntax check and still fail on Alpine because it assumes apt-get, Bash, GNU tools, or an interactive terminal. InstallReady scans a public repository and generates the runtime workflow that checks those assumptions.

Run the check now
Open the browser scanner Read the project

Typical failure

#!/bin/sh
set -e
apt-get update -qq

This is valid shell, but Alpine normally uses apk. The generated report shows the distribution and command that failed, then leaves the final fix to the project maintainer.
